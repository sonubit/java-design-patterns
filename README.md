# Java Design Patterns

A practical collection of **Java Design Patterns** demonstrating
object-oriented design, reusable solutions, and clean software
architecture principles.

The examples are implemented using Java with a focus on understanding
when and why a particular design pattern should be used.

---

## 🎯 Purpose

This repository provides practical Java implementations of commonly
used software design patterns.

The goal is to understand:

- Object-Oriented Programming
- SOLID principles
- Loose coupling
- High cohesion
- Composition over inheritance
- Reusable software design
- Maintainable application architecture
- Common enterprise design approaches

---

## 🧩 Design Patterns

### Creational Patterns

Patterns responsible for object creation.

| Pattern | Description |
|---|---|
| Singleton | Ensures a class has a single instance |
| Factory Method | Creates objects without exposing creation logic |
| Abstract Factory | Creates families of related objects |
| Builder | Constructs complex objects step by step |
| Prototype | Creates objects by cloning existing instances |

---

### Structural Patterns

Patterns that define how classes and objects are composed.

| Pattern | Description |
|---|---|
| Adapter | Makes incompatible interfaces work together |
| Decorator | Adds behavior dynamically |
| Facade | Provides a simplified interface |
| Proxy | Controls access to another object |
| Composite | Represents hierarchical object structures |
| Bridge | Separates abstraction from implementation |

---

### Behavioral Patterns

Patterns focused on communication and responsibility between objects.

| Pattern | Description |
|---|---|
| Strategy | Encapsulates interchangeable algorithms |
| Observer | Defines one-to-many object relationships |
| Command | Encapsulates a request as an object |
| Template Method | Defines an algorithm skeleton |
| State | Changes behavior based on internal state |
| Chain of Responsibility | Passes requests through a chain |
| Iterator | Provides sequential access to collections |
| Mediator | Centralizes communication between objects |
