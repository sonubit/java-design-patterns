# Java Design Patterns

Professional Java implementations of commonly used
**Object-Oriented Design Patterns**.

This repository demonstrates practical applications of
Creational, Structural, and Behavioral design patterns
using clean and maintainable Java code.

---

## 🎯 Goals

- Understand software design patterns
- Improve object-oriented design skills
- Apply SOLID principles
- Reduce coupling
- Improve maintainability
- Create reusable components
- Prepare for enterprise Java development
- Prepare for technical interviews

---

## 🧩 Design Patterns

### Creational

- Singleton
- Factory Method
- Abstract Factory
- Builder
- Prototype

### Structural

- Adapter
- Decorator
- Facade
- Proxy
- Composite
- Bridge

### Behavioral

- Strategy
- Observer
- Command
- Template Method
- State
- Chain of Responsibility
- Iterator
- Mediator
